# 内部碰撞体编辑器

> 纯编辑器工具。给场景物体的**内腔网格**补碰撞体，解决两件事：
> 1. 让[物品摆放工具](物品摆放工具.md)的**内部采样**能打到内腔层板 / 内壁；
> 2. 让摆进去的物品有**实体托住**，运行时不会掉落、穿出台面。
>
> 菜单入口：`Tools/DownBreak/内部碰撞体编辑器`

---

## 1. 为什么需要它

这套工具链里，**"表面"完全由碰撞体定义**：

- 采样靠 `Physics.Raycast` —— Unity 射线**只认 `Collider`**，没有碰撞体的 Mesh 对射线是"透明"的；
- 采样区域也来自碰撞体 `Collider.bounds`；
- 运行时物品靠刚体与碰撞体落位，没有承托面就会自由落体。

所以内腔能不能摆东西，取决于内腔**有没有可被射线命中的、法线朝上的碰撞体面**：

| 内腔情况 | 现状 | 需要做的事 |
|---|---|---|
| 有独立几何（层板 / 内壁 mesh），但**没挂碰撞体** | 内部采样打不到，物品也会穿下去 | 用本工具补 `BoxCollider` / `MeshCollider` |
| 内腔就是**外壳的内表面**（单一封闭网格，法线朝外） | 默认打不到：从内部往外打命中的是**背面**，而 `Physics.queriesHitBackfaces` 默认关闭 | 给外壳加 `MeshCollider` + 打开背面命中，或在内腔单独放一块"内底板"碰撞体 |
| 只有**一个实心 `BoxCollider`**（没有内腔几何） | 物理上不存在"内部面" | 用**锚点模式**（锚点自带承托碰撞体）或把运行时行为设为「保持编辑位置」，不依赖内腔碰撞体 |

---

## 2. 界面说明

- **目标物体**：要编辑的场景物体（默认取 Hierarchy 当前选中），必须是**场景实例**且**激活**；
- **统计行**：`子网格 N 个，其中无碰撞体 M 个`；
- **批量**：
  - `优先用 MeshCollider`：勾选时优先按网格生成 `MeshCollider`，没有 `MeshFilter` 的网格自动退回贴合 `BoxCollider`；
  - `为缺失的网格生成碰撞体`：跳过**已有碰撞体**的网格，只补缺失的；
  - `移除本工具生成的碰撞体`：删除全部由本工具生成的节点；
- **网格明细**（逐行，按层级缩进）：
  - 状态：`无碰撞体` / `已有碰撞体` / `已生成 贴合盒` / `已生成 网格`；
  - `贴合盒`：按 `Renderer.localBounds` 生成贴合 `BoxCollider`；
  - `网格`：生成 `MeshCollider`（需要 `MeshFilter`）；
  - `移除`：只移除本工具生成的碰撞体，不动美术自带的；
  - `选中`：在 Hierarchy 里定位该网格。

所有操作都走 `Undo`，可以 `Ctrl+Z` 回退。

## 3. 生成物约定

生成的碰撞体不会动美术原来的组件，而是挂在渲染器下的子节点上：

```
冰箱                       ← 目标物体
├── 外壳(MeshRenderer)     ← 原有网格
│   └── InteriorCollider_Box   ← 本工具生成的贴合 BoxCollider
├── 层板A(MeshRenderer)
│   └── InteriorCollider_Mesh  ← 本工具生成的 MeshCollider
└── 层板B(MeshRenderer)    ← 无碰撞体（状态：无碰撞体）
```

- 子节点名字固定为 `InteriorCollider_Box` / `InteriorCollider_Mesh`，便于整体识别与移除；
- 子节点继承渲染器的变换（含缩放），所以贴合盒与网格在世界空间里与模型一致。

## 4. 与摆放工具的配合

两种推荐组合：

**A. 纯摆场（最省事，推荐）**

1. 摆放工具的「运行时行为」选 **`保持编辑位置`**；
2. 用**锚点模式**摆物品，勾「生成前补承托碰撞体」；
3. 不需要给内腔补碰撞体——物品进 Play 后原地不动，也不会被挤压顶飞。

**B. 有物理表现（能被撞掉、会滑落）**

1. 先用本工具给**层板**补碰撞体（状态从「无碰撞体」变成「已生成」）；
2. 摆放工具里「采样范围」选 `顶面 + 内部` 或 `只采内部`，勾「避免穿模(净空检查)」；
3. 「运行时行为」选 **`正常世界掉落物`**，让物品落在层板上；
4. 干跑统计确认没有「净空不足 / 射线未命中」的报错。

---

## 5. 注意事项

- **不要勾 `Is Trigger`**：本工具生成的碰撞体一律 `isTrigger = false`（触发器不参与射线表面采样，也不能承托物品）；
- **`MeshCollider` 非 Convex 也能被射线命中**，只有需要参与刚体碰撞时才必须 Convex。冰箱外壳这类大网格建议用非 Convex；
- 补碰撞体会增加物理开销，**只给需要摆放/承托的网格补**即可（例如只给层板，不给整颗装饰螺丝）；
- 内腔碰撞体是**实体**，会影响玩家碰撞与其它系统的射线；如果只想让物品"摆着不动"，用组合 A，不要补碰撞体。
