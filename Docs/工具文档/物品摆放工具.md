# 物品摆放工具（表面 / 内部 / 锚点）

> 纯编辑器工具，**不参与运行时逻辑**。用于把物品表里的世界掉落物批量摆到场景物体上（桌面、货架、冰箱内腔……）。
>
> 菜单入口：`Tools/DownBreak/物品表面摆放`（层级右键 `GameObject/DownBreak/在表面随机摆放物品`）
>
> 设计动机、算法取舍与已知限制见 [`物品摆放工具-设计说明.md`](物品摆放工具-设计说明.md)。

---

## 1. 快速上手

1. 打开窗口，**目标物体** 选场景里要摆东西的物体（或点「取当前选中」）；
2. 选 **摆放方式**：
   - `表面采样` —— 在目标碰撞体的表面上自动撒点；
   - `放置锚点` —— 在场景里手工摆锚点，一个锚点一个落点（可控性最好）；
3. 选 **物品来源**（物品表 ID 列表 / 按类型随机）→ 点 **干跑统计** 看能不能摆上、失败原因 → 点 **生成**。

生成的物品是**预制体实例**（保持预制体关联），可整体 `Ctrl+Z` 撤销，也可用「清空生成物」一键清除。

---

## 2. 三种摆放方式

### 2.1 表面采样 · 顶面

在目标（自身 + 子物体）碰撞体的包围盒内随机撒点 → 从顶上向下打射线 → 只接受**法线朝上**（倾角 ≤ 阈值）且命中目标自身碰撞体的面。

关键参数：

| 参数 | 作用 |
|---|---|
| `表面层` | 参与射线的层；**目标自身所在层会自动并入**（冰箱/箱子这类在 `Interactable` 层的物体不会被掩码挡掉） |
| `只取目标自身碰撞体` | 关掉后允许落在同层的其它物体表面上 |
| `水平内缩` | 撒点范围距包围盒边缘的内缩，避免贴边悬空 |
| `最小间距` | 生成点之间的间距下限，实际取值 = `max(最小间距, 物品自身宽度)`，避免两件物品叠在一起 |
| `最大表面倾角` | 超过视为墙面，不摆放 |
| `射线上抬 / 射线额外长度` | 射线起点与长度 |
| `单点采样次数` | 一个点位最多尝试多少次撒点 |
| `避免穿模(净空检查)` | 在承托面上方放一个按物品尺寸收缩 0.85 的盒做重叠测试，压到实体几何就换点 |

### 2.2 表面采样 · 内部

用于把物品摆进**内腔**（冰箱隔板、货架层板）：

- **自动模式**：在目标包围盒**内部**随机高度向下打射线，打到哪层算哪层；
- **显式模式**：把内腔的层板/内壁拖进「内部表面」列表（有「用当前选中」一键添加），只在这些面上采样，并且是**多命中里挑最近的内部面**——能越过箱体外壳之类的遮挡物；
- 可选 `要求头顶有遮挡`：只有被真正包住的空间才算"内部"。

> 前提：内腔必须有**能被射线命中的碰撞体**。没有的话用 [`内部碰撞体编辑器`](内部碰撞体编辑器.md) 补，或改用锚点模式。

### 2.3 放置锚点（推荐）

在场景里手工摆 `ItemPlacementAnchor` 组件，精确控制每件物品的位置：

- 菜单 `GameObject/DownBreak/添加物品放置锚点`（默认落在父物体碰撞体顶面中心）；
- **锚点原点 `transform.position` 就是承托面**，局部 **+Y = 承托面法线**（物品站立方向），场景里拖动/旋转即可；
- Gizmo 会画出「承托台（平面下方）+ 平面细框 + 向上箭头 + 名称/范围/件数」；
- 每锚点可单独设置：

| 字段 | 说明 |
|---|---|
| `散布方式` | `单点` —— 物品就摆在锚点原点（每锚点默认 1 件，多件可用 `jitterRadius` 抖开）；`范围` —— 在 `areaSize` 内随机撒开 |
| `areaSize` | 范围锚点的平面范围（X 宽 / Z 深），Y 兼作承托台厚度 |
| `placeCountOverride` | 该锚点件数，0 = 用工具全局件数 |
| `surfaceOffset` | 该锚点的离面抬升（覆盖工具全局值） |
| `randomYaw` | 随机水平朝向 |
| `可作为承托面` | 允许一键生成承托碰撞体 |
| `jitterRadius` | 单点模式下的小抖动半径 |

**承托碰撞体**：锚点检视面板或窗口里可「生成/更新承托碰撞体」——在锚点下建 `AnchorSupportCollider` 子节点，挂一块薄 `BoxCollider`，**顶面与锚点面完全重合**，让物品有实体托住；可随时移除。

## 3. 落位规则

| 设置 | 行为 |
|---|---|
| `落位对齐 = 底面贴承托面`（默认） | 取**渲染器 + 碰撞体包围盒在承托面法线方向的最低点**，对齐到「承托面 + 离面抬升」。视觉与物理都正确；Transform 的 y 会比锚点高一个「轴心→模型底部」的距离 |
| `落位对齐 = 轴心对齐锚点` | 轴心直接落在锚点位置，**Transform 数值与锚点完全一致**；轴心在模型中间的预制体会半埋（适合轴心已在模型底部的物品） |

`离面抬升` 默认 0.02m，用于避免与承托面共面导致的物理抖动。

## 4. 运行时行为

生成时写入实例，决定进 Play 后的表现：

| 模式 | 行为 |
|---|---|
| `保持编辑位置`（默认，推荐） | 物品 `isStaticPlaced = true`，`ItemPhysicsUtil.PrepareStaticPlaced()` 把刚体置为**运动学 + 关重力**：不随机翻姿态、不下落、**不会被碰撞挤压顶飞**；碰撞体保持实体，依旧是**正常可拾取物品** |
| `正常世界掉落物` | 走原世界掉落流程：进 Play 随机姿态自由下落，落地后碰撞体转 Trigger。**必须下方有实体碰撞体托住**，否则会穿出台面/被去穿透顶出去 |

> 为什么默认不是"正常掉落物"？`ItemPhysicsUtil.PrepareWorldDrop()` 第一件事是 `transform.rotation = Random.rotationUniform`，编辑器里摆好的姿态会被随机打乱并开始下落——物品会从架子/冰箱里滚出去。编辑器摆场物默认走固定摆放路径。

## 5. 与运行时系统的关系

- 生成物 = 世界掉落物预制体（`world_prefab_path`）+ `ItemInteract`，写入 `itemTableID`；堆叠 > 1 时写入实例快照（`saveData`）；
- **交互优先级**：`InteractPriorityUtil` 规定 `可拾取物品(100) > 按压式(60) > 容器/工作台(20) > 普通(0)`，同一优先级再按命中距离。`InteractionDetector` 现在会在一次球投射的**全部命中**里按该规则挑选目标——摆在架子/冰箱里的物品不会被架子挡住；
- 拾取走既有链路：`PickupInteractModule` → `IUIBagInteract.TryPickupWorldItem`。

## 6. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| Play 后物品被顶飞、翻滚 | 运行时行为是「正常世界掉落物」→ 改成「保持编辑位置」；或物品被摆进了实心碰撞体内部 |
| 干跑/生成全失败，原因「射线未命中」 | 目标自身/子物体没有**非 Trigger** 碰撞体；目标未激活；或选的是 Project 里的预制体资源（不是场景实例）。提示：`Prefab Mode` 下射线查的是主场景物理场景，采不到预制体内容 |
| 原因「净空不足放上去会穿模」 | 摆点周围空间不够（贴墙/已在物品堆里）。调小 `最小间距`、放大锚点范围，或关掉「避免穿模」 |
| 原因「内部空间头顶没有遮挡」 | 勾了 `要求头顶有遮挡`，但该点上方没有目标自己的几何 |
| 「位置和锚点不一样」 | ① 锚点是 `范围` 散布 → 切 `单点`；② `落位对齐` 是 `底面贴承托面` → Transform 会高出一个轴心到模型底部的距离，想数值一致就切 `轴心对齐锚点`。生成结果里会打印「锚点最大水平偏差」，单点模式应 ≈ 0 |
| 内部采不到 | 内腔没有碰撞体 → 用 [`内部碰撞体编辑器`](内部碰撞体编辑器.md) 给层板/内壁补 |
| 重开背包出现搜刮容器栏 | 已修：`BagPanel.OnShow/OnHide` 统一走 `BagMainContainerMgr.HideSearchAndClearActive()` |
