# DownBreak 资源管线（MmAsset）

> 目标：对齐 Addressables——**内核主地址 = 完整路径**；**业务 / Excel 只填短名 Address**。
> 原则：短名经 `assetAliasList` 解析成路径再加载；**表里不出现 `Assets/...`**；不靠类型后缀魔法拆一名多物。

最后核验：2026-08-12

---

## 一、分层（别搞反）

| 层 | 填什么 | 谁维护 |
|---|---|---|
| **Excel / UI 窗口名** | 短名 Address（如 `小刀`、`BagPanel`） | 策划 / 业务 |
| **assetAliasList** | 短名 → 具体资产 | 模块配置（可「按文件名填充」） |
| **AbConfig / 运行时** | path + alias；CRC(path) 主键 | 导出地址表 |

```
Excel 短名
  → aliasItemDict
  → BundleItem.path（完整路径）
  → Editor AssetDatabase / 真机 AB
```

代码调试或框架自举（如 Stat SO）可以直接传完整路径；**那是代码的事，不要写进 Excel。**

---

## 二、业务字段约定

| 字段 | Excel 填法 |
|---|---|
| `icon_path` | 短名（须注册） |
| `world_prefab_path` / `utensil_prefab_path` | 短名（须注册） |
| `eat_anim_name` / `use_anim_name` | FP Animator **状态名**（不是资源 Address） |
| UI 窗口打开名 | 短名（须注册） |

**一名一条**：图标与掉落 Prefab 是两个资产 → 必须两个不同短名。约定：`icon=小刀图标`，`world=小刀`（Prefab 用物品本名，图标统一加「图标」后缀）。禁止「同短名靠 Sprite/Prefab 类型分叉」。

磁盘文件名可无类型后缀（见清理清单）；唯一性靠别名注册，不靠文件名后缀。

---

## 三、导出与加载

`GenerateAssetAlias`：

1. Shader 变体特殊名  
2. `assetAliasList` 命中 → 短名  
3. 否则 → 完整路径（仅保证导出不撞；业务仍应注册短名）

`TryGetBundleItem`：先短名，再 `CRC(address)`（故代码可直传路径）。

---

## 四、运行时链路

```
ModuleHub → MmAssetBootManager → BootModule(BuidinPack)
业务 → MmAssetMgr.Load*(短名)
     → ResourceManager → path → Editor / AB
```
