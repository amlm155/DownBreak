# DownBreak 配置管线（ScriptableObject）

> 目标：运行时调参、挂点、动画模组、GAS 状态等走 **Unity SO / Resources**，在 Inspector 改，不经 Luban。
> 原则：表数据（物品/搜刮行）归《数据管线》；资源短名归《资源管线》；本篇只写 **SO 与 Editor 配置资产**。

最后核验：2026-08-12

---

## 一、边界（三管线）

| 管线 | 管什么 | 改哪里 |
|---|---|---|
| **配置管线（本文）** | 调参 SO、挂点字典、动画资产引用、GAS Stat/Tag、框架 BundleSettings、UI 生成路径 | `.asset` / Editor json |
| **数据管线** | 物品/搜刮表结构 + Excel 行数据 | `DataTables/` → gen |
| **资源管线** | 短名别名、AB、Boot、`MmAssetMgr` | 资源文件名 + Generated AbConfig |

跨表对齐（须两边一起改）：

- Luban `EWeaponName` ↔ `WeaponConfig` 字典 Key
- Luban `animation_type` ↔ `EAnimationModelType` / `AnimationModelSoData`
- Luban `icon_path` / `*_prefab_path` ↔ 短名 Address（`assetAliasList`）；`*_anim_name` ↔ Animator 状态名（见资源管线）

## 三、各 SO 职责摘要

### PlayerConfig
体力回复/消耗、饥渴衰减、蹲站高度与速度倍率、FOV 等 **3C 调参**。全局单例，玩法数值微调优先改这里，不要塞进 Luban。

### WeaponConfig
按 `EWeaponName` / 消耗品 id 存 **手持本地 Pose**（右手武器、左手道具、食物餐具、药品等）。与表里的 `weapon_name`、消耗品演出挂点对齐；改挂点用武器配置编辑页，勿手改备份 json（`WeaponConfig.backup.json` 仅备份）。

### AnimationModelSoData（FpAnimationAssets）
FP 动画模组资源引用（与 `animation_type` 对齐）。挂在 `PlayerAnimationController` 上。

### GASConfig
`PlayerState`：Health / Food / Water / Power / San / MoveSpeed 等 Stat 定义。  
`Tag`：如 StandTag。启动时 `LoadAll` 进属性系统。

### BundleSettings
MmAsset 加载模式（Editor / AssetBundle）、热更 URL、加密、构建平台等。详见《资源管线》。

## 五、改配置怎么做

1. 在 Project 选中对应 `.asset`，Inspector / Odin 改字段  
2. 需要新建时用上面 CreateAssetMenu，放进既有 `Resources/Config/...` 目录以保持 Load 路径  
3. 若 Key 对齐 Luban 枚举：先改/gen 表枚举，再改 SO 字典 Key，最后跑一遍装备/进食验收  
4. **不要**把物品行数据写进 SO；行数据只走《数据管线》

## 六、与数据管线交叉

查表入口仍是 `LubanTables`（见数据管线）。典型组合：

```csharp
var weaponRow = LubanTables.Tables.TbWeapon.GetOrDefault(itemTableId);
// weaponRow.WeaponName → WeaponConfig.TryGetHandPosConfig(...)
```

资源短名加载走 `MmAssetMgr`（见资源管线），SO 里一般只存引用或枚举 Key，不存完整 Assets 路径。
